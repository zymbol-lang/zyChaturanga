## किमर्थं संस्कृतम्?

क्रीडा भारतीया। प्रथमं संस्कृतेन एव वर्णिता, तस्याः नाम च संस्कृतसमासः:
**चतुर्-अङ्ग**, सेनायाः चत्वारि अङ्गानि। अङ्गानि एव क्रीडायाः अङ्गानि:

| संस्कृतम् | सेनाङ्गम् | अभवत् |
|-----------|-----------|-------|
| पत्तिः | पदातिसेना | peón · pawn |
| अश्वः | अश्वसेना | caballo · knight |
| रथः | रथसेना | torre · rook |
| गजः | गजसेना | alfil · bishop |
| मन्त्री | अमात्यः | dama · queen |
| राजा | नृपः | rey · king |

अतः संकेतः संस्कृतेन एव लिखितः। प्रत्येकं नाम, प्रत्येकं मॉड्यूलनाम, प्रत्येकं
सञ्चिकानाम च देवनागर्याम्। एतेन Zymbol इति परियोजनायाः एकं रिक्तं स्थानं पूर्यते:
जापानी (囲碁), कोरियाई, चीनी (ZyAudit), क्लिंगन (Hov veS), स्पानिश्, यूनानी च
पूर्वम् एव आसन् — भारतीया लिपिः तु नासीत्।

**मुखम्** पञ्चसु भाषासु: संस्कृतम्, हिन्दी, फ़ारसी, आङ्ग्लम्, स्पानिश् — यस्यां
जाता, यस्याम् अद्य क्रीड्यते, यया पश्चिमं गता, याभ्यां च एषा परियोजना लिखिता।

## नियमाः

एते प्राचीनस्य चतुरङ्गस्य चालाः, न आधुनिकस्य शतरञ्जस्य। त्रीणि अङ्गानि भिन्नानि,
तानि एव त्रीणि द्वयोः क्रीडयोः सम्पूर्णः भेदः।

| अङ्गम् | गतिः | न तु |
|--------|------|------|
| राजा | एकं पदं सर्वासु दिक्षु | गृहत्यागः नास्ति |
| मन्त्री | **एकं पदं तिर्यक्** | न राज्ञी: पत्तेः अनन्तरं दुर्बलतमम् |
| रथः | दूरं ऋजु | यथा सदा |
| अश्वः | अश्वस्य उत्प्लवः | सहस्रवर्षेषु अपरिवर्तितः |
| गजः | **द्वे पदे तिर्यक् उत्प्लवते**, मध्यम् अतिक्रम्य | न आधुनिकः गजः: अष्टौ एव पदानि |
| पत्तिः | एकं पदम् अग्रे, तिर्यक् गृह्णाति | **न द्विपदप्रयाणम्**, न वरणविकल्पः |

| नियमः | फलम् |
|-------|------|
| प्रवर्धनम् | अन्तिमां पङ्क्तिं प्राप्तः पत्तिः मन्त्री भवति — अन्यत् किमपि न |
| मातः | पराजयः |
| **गतिरोधः** | **गतिरुद्धस्य पराजयः** — शतरञ्जस्य प्राचीनः नियमः |
| निर्वस्त्रः | एकाकी राजा: पराजयः; उभौ एकाकिनौ चेत् समता |

**किमर्थं गतिरोधः अत्र जयः।** मन्त्री गजः च दुर्बलौ, अन्ते च फलकं शून्यप्रायम्।
आधुनिकेन नियमेन समयोः क्रीडकयोः प्रायः सर्वा क्रीडा समतायाम् एव अन्तं गच्छेत्।

## मतिः

अल्फा-बीटा गवेषणा। एषः एव GO इति क्रीडायाः सह गभीरतमः भेदः: **तत्र प्रतिस्थितौ
त्रिशतम् अधिकाः चालाः, गवेषणा च व्यर्था; अत्र विंशतिः प्रायः, अतः गवेषणा एव
योग्या रीतिः।** तत्र स्थानस्य ज्ञानम्, अत्र गणना।

| स्तरः | गभीरता | विक्षेपः |
|-------|--------|----------|
| आरम्भकः | १ | २०० |
| मध्यमः | २ | ६० |
| निपुणः | ३ | २० |

स्तरः "जानन् दुष्टं क्रीडति" इति न। स तु **विक्षेपः**: श्रेष्ठात् कियत् न्यूनं
मूल्यं सहनीयम्, और तेषु समेषु यादृच्छिकं चयनम्। आरम्भकः दुष्टं न क्रीडति; स तु
श्रेष्ठं प्रायःश्रेष्ठात् भेत्तुं न शक्नोति — और द्विशतम् एव अङ्गस्य मूल्यम्।

अङ्गमूल्यानि अस्याः क्रीडायाः, न शतरञ्जस्य:

```
पत्तिः  १००     गजः  १५०     मन्त्री  २००     अश्वः  ३००     रथः  ५००
```

रथः मन्त्रिणः अधिकः, और अश्वः गजमन्त्रिणोः मिलितात् अपि अधिकः। यस्यां क्रीडायां
राज्ञी एकपदी और गजः अष्टपदः, तस्यां रथः एव फलकस्य राजा।

## अङ्काः अपि अनूद्यन्ते

एतत् एव यत् चतुरङ्गम् 囲碁 इत्यस्याः i18n-रचनायै योजयति: **भाषायाः चयनम्
अङ्कलिप्याः चयनम् अपि।**

```zymbol
?? संकेतः {
    "fa" => { #۰۹# }      // विस्तृतम् पूर्वारब्यम्
    "en" => { #09# }
    "es" => { #09# }
    _    => { #०९# }      // देवनागरी
}
```

चित्रणस्य संकेतः न जानाति का लिपिः प्रवृत्ता। एका एव पङ्क्तिः यया पदस्य नाम
रच्यते, सा `e४`, `e۴`, `e4` इति ददाति।
